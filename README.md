# Genshin Wish Calculator

A browser-based planning tool for Genshin Impact's wish system: plan pulls across upcoming patches, forecast outcomes with pity, guarantee and Capturing Radiance handling, check 4★ odds, and run a pull simulator.

**Live site:** https://spektrem2b.github.io/genshin-wish-calculator/

## About this repository

This repository is generated build output. It contains the published site only, and it is force-pushed on every release, so there is no meaningful history here. Issues and pull requests are not monitored, and contributions are not accepted. For questions, see the [contact page](https://spektrem2b.github.io/genshin-wish-calculator/contact.html).
