Privacy Policy

Last updated: September 2026 (removed Teams tab clauses, feature discontinued)

Genshin Wish Calculator does not require an account, and does not collect or store any personal data on any server. Calculation inputs are sent to a backend script only to compute results (see below) and are not retained.

What stays on your device

Any information you enter (pity counts, inventory, build data, saved settings) is stored using your browser's localStorage. This data never leaves your device and is never sent to any server, except where this page says otherwise (Forecast calculations, below). Clearing your browser data or using a different browser/device will remove it.

Forecast calculations

When you click "Calculate" on a wish forecast, the inputs behind that calculation (pity counts, target list, income settings, and similar) are sent to a small backend script (a Cloudflare Worker) run by this site's owner, which performs the math and returns the result. This happens only when you click Calculate, not continuously and not in the background.

The Worker does not store these inputs; each request is processed and discarded. To prevent abuse (e.g. automated scripts hammering the calculator), the Worker briefly and temporarily records the requesting IP address to enforce a rate limit; this is not linked to any profile or identity and is not retained beyond that short window.

To avoid re-sending the same calculation repeatedly, recent results are cached locally in your browser via localStorage (see above); this cache never leaves your device.

Google Drive Sync

The Settings tab lets you optionally back up your local calculator data (pity, inventory, and similar) to your own Google Drive, so it can be restored on another device.

Sync is off by default and only activates if you explicitly sign in and press Connect/Sync — it never runs automatically, including on page load. Your data goes directly from your browser to your Google Drive account using Google's own APIs; this site's servers/Worker never see or store a copy of it. The connection also isn't remembered between visits: closing the tab or reloading the page requires signing in again, since no token is ever saved to your device.

The app requests the narrow drive.appdata Google permission, which is even more restricted than a normal app folder: it can only read/write one hidden file in a special app-data area that isn't visible in your regular Google Drive at all, and isn't reachable by any other app. It cannot see, list, or touch anything else in your Drive. Disconnecting the app from your Google account does not automatically delete that hidden file; you'd need to remove it via your Google Account's connected-apps settings.

Third-party data sources

To show up-to-date game data, this site pulls publicly available information from:

  • ambr-py: character, weapon, and banner data
  • Ennead.cc: event calendar data
  • Hashblen: redeem code data

These requests happen from your browser directly to those services to display data on the page; no personal information is sent as part of them beyond standard, anonymous HTTP request info (which is normal for any web request and outside this site's control).

Analytics

This site uses GoatCounter to see basic, anonymous visit counts (e.g. how many people visit, and roughly which pages). It does not use cookies, does not store your IP address, and does not build any profile of you across visits or sites. This is only used to see whether the site is being used at all; it plays no role in the calculator's functionality.

Hosting

This site is hosted on GitHub Pages, which may log basic, anonymized request data (e.g. IP address, timestamp) for infrastructure and security purposes, as is standard for any web host. This site's owner does not have access to personally identifying analytics.

Changes

If this policy ever changes, this page will be updated to reflect that.
