Privacy Policy

Last updated: August 2026 (added Worker disclosure)

Genshin Wish Calculator does not require an account, and does not collect or store any personal data on any server. Calculation inputs are sent to a backend script only to compute results (see below) and are not retained.

What stays on your device

Any information you enter (pity counts, inventory, build data, saved settings) is stored using your browser's localStorage. This data never leaves your device and is never sent to any server. Clearing your browser data or using a different browser/device will remove it.

Forecast calculations

When you click "Calculate" on a wish forecast, the inputs behind that calculation (pity counts, target list, income settings, and similar) are sent to a small backend script (a Cloudflare Worker) run by this site's owner, which performs the math and returns the result. This happens only when you click Calculate, not continuously and not in the background.

The Worker does not store these inputs; each request is processed and discarded. To prevent abuse (e.g. automated scripts hammering the calculator), the Worker briefly and temporarily records the requesting IP address to enforce a rate limit; this is not linked to any profile or identity and is not retained beyond that short window.

To avoid re-sending the same calculation repeatedly, recent results are cached locally in your browser via localStorage (see above); this cache never leaves your device.

Third-party data sources

To show up-to-date game data, this site pulls publicly available information from:

  • ambr-py: character, weapon, and banner data
  • Ennead.cc: event calendar data
  • Hashblen: redeem code data

These requests happen from your browser directly to those services to display data on the page; no personal information is sent as part of them beyond standard, anonymous HTTP request info (which is normal for any web request and outside this site's control).

Hosting

This site is hosted on GitHub Pages, which may log basic, anonymized request data (e.g. IP address, timestamp) for infrastructure and security purposes, as is standard for any web host. This site's owner does not have access to personally identifying analytics.

Changes

If this policy ever changes, this page will be updated to reflect that.
